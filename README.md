# What would Picard do?

Picard was a father figure I admired, and he shall be missed. I wished to keep a small part of him near, for times when I need a reminder of what he was and what he stood for.

`/what-would-picard-do` is a Claude Code skill that offers guidance based on Picard's wisdom and values. It draws on his personality and experiences, as they were publicly eternalized.

## Install

Clone this repository and copy the `what-would-picard-do` folder into your Claude Code skills folder.

**macOS / Linux**

```bash
git clone https://github.com/ehasin/what-would-picard-do.git
cp -r what-would-picard-do/what-would-picard-do ~/.claude/skills/
```

**Windows (PowerShell)**

```powershell
git clone https://github.com/ehasin/what-would-picard-do.git
Copy-Item -Recurse what-would-picard-do\what-would-picard-do $HOME\.claude\skills\
```

Restart Claude Code, and the skill is ready.

## Use

Run the command with your question:

```
/what-would-picard-do <your question>
```

You can also ask Claude "What would Picard do about…?" Follow-up questions get answers in the same spirit, until you change the subject.

## Example

```
/what-would-picard-do What's the proper way to serve Earl Grey tea?
```

> *a faint smile*
>
> At last, a question I can answer with complete authority. Warm the pot first. Use loose leaf, a good teaspoon per cup, and water just off the boil. Let it steep three to four minutes and no longer, or the bergamot turns bitter. Then take the leaves out. Milk is a matter of conscience; I take mine without. And serve it hot. Lukewarm Earl Grey is an apology, not a cup of tea.
>
> But tell me: is this for a quiet moment alone, or are you pouring for someone?
